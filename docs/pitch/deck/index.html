How we will prove it
Proposed gates · not performance claims

Delivery gates, not promises.

INTEGRITY

Old passports still verify

Existing routes and on-chain checks keep working. New hashes reproduce deterministically.

QUALITY

Measured against the MVP

Benchmark, recall, citation exactness and abstention reported. No gains claimed before measuring.

FRESHNESS

A correction becomes a version

One verified source correction creates a new immutable version, an accurate delta and one notification.

AGENTS

A missing field is never a pass

Policy calls are deterministic and every decision receipt is bound to an exact Passport and method.

SECURITY

Hostile input cannot steer scoring

Prompt-injection and SSRF test fixtures fail to change tools or scores. Private data stays private.

HONESTY

No invented integrations

Unavailable capabilities are marked unsupported, never faked with fabricated receipts or results.
