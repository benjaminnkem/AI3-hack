07 / The Truth Score

A formula you can audit.

Per-claim score
0.60 × evidence  +  0.40 × model mean
− adversarial penalty (capped at 20)
Evidence is weighted by source quality × relevance, and pulled toward 50 until three or more distinct domains agree.
Confidence = model confidence 35% · agreement 25% · domain coverage 25% · source quality 15%.
70–100Supported
50–69Unverified
25–49Misleading
0–24Contradicted
Models don't pick the number, and the final narrative can't change it.

10 / Built to be trusted

Decentralized inference. Honest limits.

Decentralized AI

Every inference call runs through Gonka Router. No single provider defines the answer, and models are swappable, with fallback when one is retired.

Live evidence

Tavily retrieves current sources for each claim, with titles, dates, excerpts and quality, and a query built to find contradictions.

Guardrails shipped

SSRF and DNS checks, MIME and 5 MB limits, schema validation, rate limits, server-only secrets, hashes-only on-chain.

Honest limits AI can be wrong · prompt-injection defenses are basic · OCR is English-only · a score is an assessment, not an oracle.

11 / Where it goes
Proposed roadmap

From a one-time check to living evidence.

Mesh Memory

One claim graph across posts, screenshots and translations.

Living Passports + Watch

Immutable versions and one alert when evidence really changes.

Lens + Share-to-Mesh

Context where claims appear: browser layer, Telegram, WhatsApp pilot.

MCP + Trust Policy

Typed tools for agents; high-risk actions escalate when evidence is stale.

MethodHash

Attest the method and version, not just the artifact.

Mesh Bench + Firewall

Public accuracy metrics; retrieved text treated as untrusted input.

Gated pilots, only after the foundations are measurable: audit cases · market resolution dossiers · evidence bounties · zkTLS private-source proofs · zero-knowledge passports. A score never moves money by itself.
Evidence assessment ≠ cryptographic integrity ≠ real-world truth
